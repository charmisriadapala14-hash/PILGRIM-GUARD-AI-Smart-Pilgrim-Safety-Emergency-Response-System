
🛡️ PILGRIM GUARD AI

Smart Pilgrim Safety & Emergency Response System Using Agentic AI and RAG

📌 About the Project

PILGRIM GUARD AI is an intelligent safety and emergency response platform designed to protect pilgrims during large religious gatherings.

It uses Agentic AI and Retrieval-Augmented Generation (RAG) to provide intelligent assistance, emergency support, and missing person management.

🎯 Problem Statement

During crowded pilgrimages, children and elderly people may get separated from their families. Medical emergencies and other safety issues can also occur.

Traditional systems may face difficulties providing quick assistance.

Our project aims to provide a smart and centralized solution for pilgrim safety.

✨ Key Features

- 🚨 Emergency Registration
- 🔔 Emergency Alert Notifications
- 👨‍👩‍👧 Missing Person Registration
- ✅ Missing Person Found Status Update
- 📩 Notification When a Missing Person Is Found
- 🤖 AI-Powered Assistant
- 🧠 Agentic AI
- 📚 Retrieval-Augmented Generation (RAG)

🛠️ Technologies Used

- Python
- FastAPI
- React
- JavaScript
- HTML
- CSS
- Agentic AI
- Retrieval-Augmented Generation (RAG)

⚙️ System Workflow

1. Users access the platform.
2. Users register emergency or missing person details.
3. The system processes the submitted information.
4. Alerts are generated for registered emergencies.
5. When a missing person is found, their status can be updated.
6. A notification informs the concerned users.
7. The AI assistant provides relevant information using RAG.

🎯 Project Objective

To develop an AI-powered safety platform that improves emergency response, helps reunite missing pilgrims with their families, and provides intelligent assistance.
